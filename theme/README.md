# Lucent Theme

This directory is the standalone Lucent visual theme for Pegasus Frontend.

Copy or extract the directory into Pegasus's theme folder, then select
**Lucent** in Pegasus settings. The theme provides Lucent's layouts,
navigation, responsive single- and dual-screen presentation, artwork display,
sorting, and settings UI. Android services such as automatic game importing,
media downloading, direct-launch bridges, hardware integration, and app updates
require the complete Lucent application.
